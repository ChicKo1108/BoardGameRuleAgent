# 评测与实验

检索评测后端已实现：不可变数据集、显式划分、异步任务、逐题记录及完整证据指标。使用说明见 [检索评测运行手册](12-retrieval-evaluations.md)。回答生成、人工复核和不可变报告已实现，见 [回答评测手册](14-answer-evaluations.md)。以下发布门禁仍是后续设计；真实 Azul 标准集和质量验收尚未完成。

## 数据集原则

24 道社区/对话题是候选种子，不是已核验标准答案。读取中文规则书后标注并人工确认。
划分开发集和保留验收集；保留集不用于逐题调提示词。自动生成题必须审核，避免只测试生成器自己的措辞。
支持多个正确表达和多个合理证据组合，不按答案字符串相等判分。

```ts
interface EvalCase {
  id: string;
  rulesetId: string;
  category: 'recall' | 'ambiguity' | 'inference' | 'multi_turn' | 'insufficient_evidence';
  messages: { role: 'user' | 'assistant'; content: string }[];
  expectedBehavior: 'answer' | 'answer_with_assumption' | 'clarify' | 'abstain';
  requiredClaims: string[];
  forbiddenClaims: string[];
  acceptableEvidenceSets: string[][];
  severity: 'critical' | 'normal';
  split: 'development' | 'holdout';
}
```

证据标注对应稳定规则标识；规则变化时相关测试标记需复审。不同发布版本的证据映射必须显式保存。

## 实验矩阵

A 全文输入；B 关键词；C 向量；D 混合；E D+重排；F E+关联补全。
比较检索时固定生成模型、提示词和数据；比较模型时固定检索。每次只改变明确因素。
保存数据哈希、索引版本、模型、提示词、配置、运行时间。抽样重复运行评估稳定性。

## 指标

- 解析：关键文字、图例、页码与定位正确性。
- 检索：必需证据完整率、相关证据召回及排名质量。
- 答案：结论、条件、例外、合理拒答、过度拒答、歧义处理。
- 引用：真实存在与语义支持分别统计。
- 系统：P50/P95 延迟、成本、超时、降级、并发和任务恢复。

证据完整率按“至少覆盖一个可接受的完整证据组合”计算，不能只找中任意一个相关片段就算成功。

## 错误归因

资料缺失 → 补资料/拒答；解析错误 → 解析/审核；检索遗漏 → 切分/召回/补全；推导错误 → 模型/提示词/校验。
不能将所有失败归因于提示词，不能盲目增加上下文长度。

## 发布门禁提案

关键争议题人工审核全部通过；验收集跨版本引用为零；引用定位有效率 100%。
整体正确率 95% 仅是候选目标，报告必须写明题量、分类与失败严重性；有限测试不能证明生产无错误。
重大回归阻止发布。语义支持不能仅依赖模型打分，模型裁判需人工抽样校准。

报告包含配置差异、指标、失败题、原始证据、版本比较、成本和延迟。未达门禁的候选版不可对公众发布。
