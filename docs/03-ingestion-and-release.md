# 入库、切分与知识发布

发布治理后端已实现，实际 API、门禁与回滚边界见 [知识发布手册](15-knowledge-publication.md)。下述状态链是业务流程概览；实际实现分别使用不可变知识快照、索引/评测状态、发布记录和当前指针，不使用一个可任意修改的总状态字段。

## 流程及状态

文档：uploaded → parsing → awaiting_review → approved。
发布：draft → building_index → evaluating → ready → published → retired。
失败、取消、重试保存在任务状态中，业务状态不得伪装成成功。后台支持查看失败阶段和重试原因。

1. 上传原文件，记录版本、语言、来源，计算哈希。
2. 创建持久任务，立即返回任务编号。
3. Worker 调用解析器，保存原始结构化结果和页面定位。
4. 管理员对照原页审核，修复文字、阅读顺序、图例及规则关联。
5. 从审核内容生成规则单元和候选索引。
6. 生成向量、运行评测，固定发布清单。
7. 人工确认后事务切换当前版本指针。

## 解析验收

Docling 为候选。验证中文、多栏、否定词、条件和例外、计分数字、表格、图例、页码与坐标。
自动图例描述与模型抽取关系只能进入待审核区。无法可靠解释的关键图例阻止相关知识发布。
来源块输出协议与解析器解耦，允许未来替换解析工具。

## 审核页面

左侧展示 PDF/页面图片；右侧展示原始块、修订内容和差异。支持章节调整、合并/拆分、图例关联、关系审核。
不得覆盖原始文件和解析结果。所有修改记录操作者、时间、原因和前后版本。

## 切分算法

读取规则单元 → 继承标题 → 识别边界 → 合并同一条件的连续段落 → 过长内容按子条款切分 → 建父子与关联索引。
规则完整性优先于长度。200–500 tokens 仅为初始实验范围，非最终参数。

- 例外与被限制规则保持关联；例子关联对应规则。
- 表格片段包含行列含义；图例包含审核说明与原图定位。
- 检索文本可增加标题和别名；引用展示必须回到来源。
- 子片段召回后补齐所属规则、条件和直接例外，必要时读取父章节。
- 关联扩展限制深度、数量和 token。关键条件因预算丢失时记录证据缺口。

## 幂等与恢复

阶段幂等标识 = 输入内容哈希 + 阶段名 + 配置版本。
每阶段保存成功产物和检查点。Embedding 分批提交并记录已完成批次。
队列重试不意味着业务恰好执行一次；数据库唯一约束和幂等写入仍是必要条件。
修改输入使下游索引和评测失效。网络错误可有限重试，格式错误与审核失败需要人工处理。

## 发布与回滚

发布必须绑定不可变规则清单、完整索引和同版本评测。评测后修改内容必须重新评测。
通过事务更新当前发布指针，防止半完成版本对外可见。回滚切换完整旧发布及旧索引，不重新解析。
旧资料与证据按保留策略保存，以保证历史答案可追溯。
